# Simplenote UI

แอปโน้ต Java แบบหน้าต่างเดียวสำหรับโครงงานทีมโอ่งมังกร เป็นโปรแกรมต้นแบบที่เขียนเอง ไม่ใช่แอป Simplenote ของ Automattic และไม่ใช่โค้ดภายในของแอปจริง

## วิธีง่ายที่สุดสำหรับเพื่อนที่ใช้ Windows 64 bit

1. เปิดหน้า Releases ทางขวามือของ repository แล้วเลือกเวอร์ชันล่าสุด
2. ดาวน์โหลด `SimplenoteUI-Windows-x64.zip` จาก Assets ไม่ใช่ Source code (zip)
3. แตก ZIP **ทั้งโฟลเดอร์** ไปไว้ในพื้นที่ที่เขียนได้ เช่น `D:\Apps` อย่ารันจากใน ZIP
4. เปิดโฟลเดอร์ที่แตกได้ แล้วดับเบิลคลิก `Start-Simplenote.bat`

ชุด Windows รวม Java runtime แล้ว จึงไม่ต้องติดตั้ง Java, IntelliJ หรือส่วนขยาย VS Code อย่าย้ายเฉพาะไฟล์เปิดโปรแกรมออกจากโฟลเดอร์ เพราะยังต้องใช้ jar และ runtime ที่อยู่ข้างกัน ชุดนี้สำหรับ Windows x64 เท่านั้น ไม่ใช่ Mac หรือมือถือ ไม่ใช่ตัวติดตั้ง exe ให้แตก ZIP แล้วใช้ได้เลย

แอปไม่ได้ลงลายเซ็นดิจิทัล หาก Windows แสดงคำเตือน ให้ตรวจแหล่งดาวน์โหลดและชื่อไฟล์ก่อนตัดสินใจเปิด ไม่ต้องปิดระบบป้องกันของ Windows

## เปิดจากซอร์สใน IntelliJ

1. กด Code → Download ZIP แล้วแตกไฟล์
2. File → Open เลือกโฟลเดอร์ซอร์ส
3. เลือก JDK 8 ขึ้นไปที่ติดตั้งไว้; ถ้ายังไม่มี ให้ติดตั้ง JDK ก่อน
4. เปิด `SimplenoteApp.java` แล้วกด Run ข้าง `main`

ซอร์สที่ GitHub วางไฟล์ Java ไว้ระดับบนสุดเพื่อดาวน์โหลดง่าย ไม่ต้องใช้ Maven หรือฐานข้อมูล บน Windows ใช้ `run-source.bat` ได้ถ้ามี java และ javac ใน PATH ส่วน `SimplenoteUI.jar` เปิดด้วย `java -jar SimplenoteUI.jar` ได้เมื่อมี Java อยู่แล้ว

## ใช้งานอย่างไร

- กด **สร้างโน้ตใหม่** ใส่ชื่อและเนื้อหา แล้วกด **บันทึก** หรือ Ctrl+S
- คลิกชื่อด้านซ้ายเพื่อเปิดโน้ต ถ้ามีข้อความยังไม่บันทึกจะถามก่อนเปลี่ยนใบหรือปิดโปรแกรม
- **Undo / Redo** หรือ Ctrl+Z / Ctrl+Y ย้อนหรือทำซ้ำการแก้เนื้อหาเฉพาะโน้ตที่เปิด ไม่รวมชื่อ และล้างประวัติเมื่อเปลี่ยนใบ
- **ลบโน้ต** ถามยืนยันก่อนลบ การลบไม่อยู่ในประวัติ Undo
- โหมด **ชื่อขึ้นต้น (Trie)**: พิมพ์ `ma` พบ Market และ Math
- โหมด **ทุกคำต้องมี (AND)**: พิมพ์ `java queue` พบ Java Queue
- ติ๊ก **แสดงหลักการทำงานสำหรับนำเสนอ** เพื่อดู id และชุดผลของแต่ละคำ

ค้นเฉพาะข้อมูลที่บันทึกแล้ว ไม่ใช่ข้อความที่กำลังพิมพ์ค้างอยู่ ค้น AND เป็นคำเต็ม ไม่แยกตัวพิมพ์ใหญ่เล็ก ภาษาไทยควรเว้นวรรคเพราะไม่มีตัวตัดคำไทย เช่น `โครงสร้าง ข้อมูล` ค้น `ข้อมูล` ได้

## ข้อมูลอยู่ที่ไหน

ค่าเริ่มต้นอยู่ใน `data/notes.properties` ภายในโฟลเดอร์ที่เริ่มโปรแกรม เช่นรันจาก D ก็เก็บใน D หากรันจาก IntelliJ จะใช้ working directory ของ Run configuration บันทึกแล้วข้อมูลยังอยู่หลังปิดโปรแกรม

เก็บไฟล์ `notes.properties.bak` ของการบันทึกก่อนหน้าหนึ่งรุ่นไว้ด้วย หากไฟล์ข้อมูลเสีย แอปจะแจ้งและไม่เขียนทับเอง ให้สำรองไฟล์ก่อนกู้คืนจาก .bak อย่าเปิดแอปสองหน้าต่างแก้ไฟล์ข้อมูลเดียวกันพร้อมกัน

กำหนดโฟลเดอร์ข้อมูลเองได้ด้วย `java -Dsimplenote.dataDir=D:/MyNotes -jar SimplenoteUI.jar` ไม่ควรใส่ข้อมูลส่วนตัวลง GitHub; ชุดดาวน์โหลดไม่รวมโน้ตที่ใช้ทดสอบ

## แบ่งหน้าที่สำหรับทีมสามคน

| คน | ไฟล์หลัก | หัวข้อ |
|---|---|---|
| 1 | History.java | Stack และ Undo/Redo |
| 2 | TitleTrie.java | Trie และ Prefix Search |
| 3 | WordIndex.java | Inverted Index และ Boolean AND |

Note.java คือแบบข้อมูล NoteStore.java คือการบันทึกไฟล์ ส่วน SimplenoteApp.java เป็น UI เชื่อมทั้งสามส่วน โค้ด GUI มี event listener และ lambda สำหรับปุ่ม แต่ส่วนอัลกอริทึมหลักใช้ลูป ไม่ใช้ recursion

เอกสาร Console รุ่นก่อนอธิบายประวัติข้ามโน้ต ส่วน UI รุ่นนี้ใช้ประวัติภายในโน้ตที่เปิด เพื่อให้ตรงกับการแก้ข้อความบนหน้าจอ ไม่มีแท็ก cloud sync login หรือ OCR และไม่อ้างว่าอัลกอริทึมตรงกับระบบหลังบ้าน Simplenote จริง

## หากเพื่อนเปิดไม่ได้

- เปิด ZIP อยู่: แตกไฟล์ก่อน
- ดาวน์โหลด Source code แทนชุด Windows: ไป Releases → Assets ใหม่
- ย้ายมาเฉพาะไฟล์เปิด: แตก ZIP ใหม่ให้ครบทั้ง jar และ runtime
- ใช้ Mac/มือถือ: ชุด Windows ใช้ไม่ได้ ให้รันซอร์สด้วย JDK บนคอมที่รองรับ Java Desktop
- ใช้ซอร์สแล้วหา java/javac ไม่พบ: ติดตั้ง JDK หรือเลือก Project SDK ใน IntelliJ
- ภาษาไทยหรือบันทึกมีปัญหา: ตรวจ working directory และสิทธิ์เขียนโฟลเดอร์ เลือกโฟลเดอร์บน D ที่เขียนได้

## ทดสอบจากซอร์ส

`javac -encoding UTF-8 -d build *.java` แล้ว `java -cp build CoreTest`

ทดสอบ GUI ในโฟลเดอร์ข้อมูลใหม่ เช่น `java -Dsimplenote.dataDir=test-data -cp build GuiSmokeTest` ห้ามใช้โฟลเดอร์โน้ตจริงกับการทดสอบ GUI
